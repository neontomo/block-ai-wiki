# markdown cheat sheet

articles on the wiki are written in Markdown format, which you can learn how to use in 20 minutes.

here is a basic cheat sheet for you to get started.

<table>
  <thead>
    <tr>
      <th>Element</th>
      <th>Markdown Syntax</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Heading</td>
      <td># heading 1<br>
        ## heading 2<br>
        ### heading 3</td>
    </tr>
    <tr>
      <td>Bold</td>
      <td>**bold text**</td>
    </tr>
    <tr>
      <td>Italic</td>
      <td>*italicized text*</td>
    </tr>
    <tr>
      <td>Blockquote</td>
      <td>&gt; blockquote</td>
    </tr>
    <tr>
      <td>Ordered List</td>
      <td>
        1. First item<br>
        2. Second item<br>
        3. Third item<br>
      </td>
    </tr>
    <tr>
      <td>Unordered List</td>
      <td>

        - First item<br>
        - Second item<br>
        - Third item<br>

      </td>
    </tr>
    <tr>
      <td>Code</td>
      <td>`code`</td>
    </tr>
    <tr>
      <td>Section separator</td>
      <td>--</td>
    </tr>
    <tr>
      <td>Link</td>
      <td>[title](https://www.example.com)</td>
    </tr>
    <tr>
      <td>Image</td>
      <td>![alt text](image.jpg)</td>
    </tr>
  </tbody>
</table>

for more complex things, you can add HTML directly to the markdown file and it will render properly.
