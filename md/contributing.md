# contributing

if want to add more information to the wiki, or you notice anything wrong, don't hesitate to contribute.

## writing/editing articles
articles on the wiki are written in Markdown format, which you can learn how to use in 20 minutes, check out the [cheat sheet](/?id=markdown).

you can see an example of one of our wiki article in Markdown format here: [example](https://raw.githubusercontent.com/neontomo/block-ai-wiki/refs/heads/main/md/mac.md)

make sure to include sources when writing articles, preferrably primary sources.

## submitting

for the technically inclined, you can simply clone the repository and send a pull-request on Github: [github.com/neontomo/block-ai-wiki](https://github.com/neontomo/block-ai-wiki)

new articles are added to the [/md](https://github.com/neontomo/block-ai-wiki/tree/main/md) folder

## other ways to contribute

if you are not a technical person, you can still contribute to the wiki by writing/editing articles and sending them directly to my email. I'll fix the formatting for you.

you can also:
- share the wiki link when people ask about blocking AI
- send me suggestions for articles you want covered
- bookmark the wiki - more is coming soon!
