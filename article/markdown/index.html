markdown cheat sheet

articles on the wiki are written in Markdown format, which you can learn how to use in 20 minutes.

here is a basic cheat sheet for you to get started.

Element Markdown Syntax
Heading # heading 1
## heading 2
### heading 3
Bold **bold text**
Italic *italicized text*
Blockquote > blockquote
Ordered List 1. First item
2. Second item
3. Third item
Unordered List - First item
- Second item
- Third item
Code `code`
Section separator --
Link [title](https://www.example.com)
Image ![alt text](image.jpg)

for more complex things, you can add HTML directly to the markdown file and it will render properly.
